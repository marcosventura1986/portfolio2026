SumoQubes — Game Website

Client SumoQubes (Gaming IP)
Year 2024
Pillar Web
Duration 6 weeks
Role Web Design, UI/UX, Front-end Development, Content Strategy
Tools Figma, React, Next.js, Tailwind CSS
Visit Website →

30s Summary

  • Challenge: Appeal to casual mobile gamers while showcasing game features and driving app store conversions.
  • Approach: Character-forward design with playful interactions; clear feature breakdown; CMS for news management.
  • Outcome: Playful, family friendly portal for the game community.

Character Showcase

Large hero featuring the SumoQubes characters with subtle animations and parallax effects. Each character has a dedicated section highlighting their unique abilities.

Feature Highlights

Clear, digestible sections explaining game mechanics, social features, and progression systems. Supported by gameplay GIFs and screenshots.

Download Flow

Strategically placed app store buttons with smart detection for iOS/Android. Clear messaging about game features and social proof (ratings, downloads).
