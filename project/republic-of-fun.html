Year 2023
Pillar Web
Duration 8 weeks
Role Web Design, Front-end Development, CMS Integration
Tools Figma, HTML, CSS, JavaScript, Craft CMS

30s Summary

  • Challenge: Let the studio's creative work shine while providing easy content management for regular updates.
  • Approach: Minimal interface with large project imagery; intuitive filtering; fast-loading pages; custom CMS integration for team to manage portfolio.
  • Outcome: Elegant portfolio site that increased client inquiries by 60% and simplified internal content workflow.
## Portfolio Grid Large, filterable grid showcasing studio projects across different disciplines. Smooth transitions and hover states reveal project details without page loads. ## Project Pages Full-bleed imagery with minimal text overlay. Process documentation, client testimonials, and related work suggestions. ## CMS Integration Custom Craft CMS setup allowing the team to easily add projects, update case studies, and manage team bios without developer intervention.
