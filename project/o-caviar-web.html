Ó Caviar — E-commerce Website

Client Ó Caviar (Premium Delicatessen)
Year 2024
Pillar Web
Duration 6 weeks
Role UX/UI Design, Front-end Development, Photography Direction
Tools HTML, CSS, JavaScript, Shopify
Visit Website →

30s Summary

  • Challenge: Create an online shopping experience that matches the premium in-store experience while ensuring fast load times and smooth checkout.
  • Approach: Minimal interface that showcases products through large imagery; streamlined navigation; optimized assets; mobile-first responsive design.
  • Outcome: High-converting e-commerce site with 90+ Lighthouse scores and seamless user experience across devices.

Design System

Extended the existing brand identity into a comprehensive digital design system with reusable components, consistent spacing, and accessibility-first approach.

Product Pages

Large hero images with smooth zoom functionality; clear pricing and availability; ingredient details; related products. Mobile experience prioritizes quick add-to-cart.

Performance

Optimized images using modern formats (WebP/AVIF); lazy loading; minimal JavaScript; fast checkout flow. Achieved sub-2s LCP on desktop and mobile.
